# v2.0 计划：对准上飞院痛点的三大模块

## 模块 C（先做，是另两个的地基）：重量与平衡深化
- `ProxyAircraft` 增加 `mlw_kg`（最大着陆重量）、`mzfw_kg`（最大零油重量）字段；OpenAP 后端从 `prop.aircraft` 读取 `mlw`（已验证存在），MZFW 用公开量级值 + 文档标注
- `payload_range_table()` 补齐第三段约束：**MLW 限制段**（着陆重量 = 起飞重 − 航程油 ≤ MLW）与 **MZFW 限制**（业载 + OEW ≤ MZFW）——教科书级三段式包线（MZFW 线 / MTOW 线 / 油箱线）
- `openap_backend.payload_range_table_openap` 同步支持 MLW
- 案例 01 追加一节"三段式包线"对比图；测试 +3

## 模块 B：碳排放分析
- `src/routelab/emissions.py`：CO₂ 主数字用标准煤油排放因子 3.16 kg CO₂/kg 燃油（ICAO/IPCC 惯例，物理上严格成立），NOx/H₂O 分项演示接 OpenAP `Emission` 类（随质量/高度变化）
- `planning.plan_leg` 的 `LegPlan` 增加 `co2_kg`、`co2_per_seat_km`（需传入座位数）；Web 航线规划页的油量明细表加 CO₂ 行、指标带加"人均碳排"卡
- 案例 06 `cases/06_emissions.ipynb`：C919 代理 vs A320neo 单座公里 CO₂ 对比 + 碳成本（€/tCO₂ 情景）对航线油钱的影响
- 测试 +4（3.16 因子守恒、Emission 分项跳过保护、API 字段）

## 模块 A（主打）：全球机场适配性扫描
- **关键模型缺口补齐**：`takeoff_field_length_m()` 增加重量参数——`weight_fraction`（起飞重/MTOW），二次方近似 `TOFL(w) = 基准 × w²`（能量吸收物理量级，文档标注）；由此可解"该跑道允许的最大起飞重量 → 减载后最大业载"
- **着陆场长粗估**：`landing_distance_m() = 0.65 × 起飞场长`（学习级系数，文档标注）
- 新增 `src/routelab/adaptability.py`：
  - `adapt_for_airport(db, ac, ident, temp_c)` → 单机场适配报告（ISA 偏差、需要场长 vs 可用跑道、按场长反解的最大起飞重量与对应最大业载、✅可用/⚠️减载/❌不足 分类）
  - `scan_region(...)` 批量向量化（86k 机场毫秒级）；高高原机场从全量库按标高 ≥3500m + CN 筛出（邦达/稻城/阿里/康定等自动浮现）
- **案例 05** `cases/05_airport_adaptation.ipynb`：中国高高原专项排序表 + **全球适配地图**（86k 点 matplotlib 散点，绿=可用/黄=减载/红=跑道不足）+ 温度情景对比
- **Web 第五标签页「机场适配」**：搜索任意机场（复用现有搜索框）→ 适配报告卡 + 温度滑块；高高原中国 Top10 表（86k 地图渲染放 notebook，界面不做全量点渲染）
- 测试 +5
